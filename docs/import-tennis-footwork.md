# 《浅谈网球步法训练》阅读版

这份 PDF 是一篇 8 页文章，不是完整篇幅的书。阅读器将它整理成一册短内容，保留原文结构并按阅读顺序分为摘要与英文摘要、前言、击球顺序与步骤、脚步训练、结论、参考文献与作者信息六节。原书印刷页码为 71–78。

## 来源与内容

- 本地源文件为 `data/imports/tennis-footwork/source.pdf`；原下载文件名为 `tennis淺談網球步法訓練.pdf`。源 PDF 仍保持原样。
- PDF 含可提取文字，不需要 OCR。繁体中文已转换为简体，英文摘要和英文参考文献保留原文。逐页的原始繁体文本与简体对照文本保存在同一导入目录。
- 阅读版章节位于 `data/books/tennis-footwork/chapters/`，书籍资料位于 `data/books/tennis-footwork/book.json`。
- 第 6–7 页的三幅训练路线图来自原 PDF。第 6 页图 1、图 2 的繁体图注与场地图重叠，因此只截取包含移动箭头的场地区域，并在正文补上简体图注；第 7 页图 3 完整截取。裁切页码、坐标和源 PDF 哈希记录在 `data/books/tennis-footwork/extraction.json`。
- 正文仅进行繁简转换和阅读排版，没有改写原文论述。原始来源中的训练数字、作者信息、参考文献与表述均保留。

## 校验

导入后运行：

```bash
npm run check-content
```

现有 PDF 导入脚本针对其他书籍的固定结构，不适用于本篇短文。修改章节时请直接编辑阅读版 Markdown；更换源 PDF 或重做裁图前，先保留现有内容与导入目录中的来源记录。
