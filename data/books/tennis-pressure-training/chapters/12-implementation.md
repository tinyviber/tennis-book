我的球队真正开始压力训练是在1997年。我已列出了训练的实例，使大家对如何组织和实施训练计划，以及如何帮助教练员在压力下训练运动员有更好的理解。非常重要的一点是，每一项训练计划的制定都是在特定的一天或阶段来满足球队的需要。这些训练计划绝不是一成不变的，因为球队和球员的需要是在变化的。事实上，一旦球队需要变化和发展时，以前的训练计划便不再使用，而采用新的训练方法，应让训练来作向导，以适应新的需要。

训练计划通常主要由以下几个重点部分组成：
1. 建立优势。
2. 施加压力—一击内侧落地球。
3. 施加压力—击外侧落地球（进行90°变线）。
4. 施加压力——第一发球和接第二发球。
5. 场上站位。
6. 旋转球。
7. 凌空球—截击、高压。
8. 双打的发球和接发球。
9. 双打的发球上网。
10. 双打的截击。
11. 比赛前期阶段。
12. 一小时训练。

每次训练平均两小时，安排7~8个练习内容，通常包括

最后的练习比赛。6、7、8的内容为热身练习部分。

时间的表示有以下4种不同的方法：
1. （1×3分钟）=一轮3分钟.
2. （2×2/2 分钟）=两轮4分钟的练习，但每轮分成两个两分钟的部分。例如，一名队员练习切削球两分钟，与其对打的另外一名队员用另一种击球方式，两分钟后互换角色再练两分钟。
3. （2/2×3分钟）=在右区练习两轮3分钟，再到左区练习两轮3分钟，总共练习12分钟。这是在左右两区进行斜线练习的独特表示方法。
4. （1/1×3/3分钟）=每名队员在右区练习3分钟，左区
练习 3｜分钟，总共练习 12分钟。这种表示方法主要用于截击
热身中一人网前一人底线，网前者右区3分钟，左区3分钟，6分钟后角色互换。
### 建立优势练习
目的：强化底线基本技术，在保持底线攻击力的同时，提高成功率。

提高基本技术是建立优势练习阶段的主要目标。运动员利用积极的上旋球在底线处与对手相持，直到出现能给对手施压的机会。保持击球的攻击性，减少落网及出边线的失误。运动员或球队不论水平高低，都要经常进行此阶段的练习。

相持球中的关闭式落地球及侧身内侧正手击球
1. 小场地定向击球。

2. 5分钟热身练习。
3. 斜线击球——右区及左区（3/3×3分钟）。
4. 20个第二发球及接发球的4拍球练习。10发至少有一发上网，接发球者回球线路按线路指导原则进行。
5. 线路——内侧落地球（2×5分钟）。
6. 斜线—一侧身内侧正手击球（左区，1×2/2分钟）。
7. 线路—猛烈地正手击球（2×5分钟）。
8. 抢七两次发球机会，结束后轮换。

上网建立优势
1. 上旋球热身（8分钟）。
2. 斜线—右区及左区（3/3×4分钟）。
3. 线路—内侧落地球变线（3×5分钟）。
4. 20 个第二发球和接发球。
5. 单打比赛。

建立优势期的杀手钢
1. 上旋球热身（8分钟）。
2. 斜线——右区及左区（1×/1×3分钟）。
3. 击斜线和90°变线球（1/1×3分钟）。
4. 斜线—侧身内侧正手（左区，2×2/2分钟）。
5. 线路—内侧关闭式落地球变线（1×5分钟）。
6. 线路——侧身内侧正手击球（2×5分钟）。
7. 第一拍球练习（2×3/3分钟）。
8. 单打抢七。

建立优势站位
1. 5分钟热身练习。
2. 斜线击球—右区及左区（2/2×3分钟）。
3. 线路—击内侧90°变线球（2×5分钟），进行900变线时要有一个良好的站位。
4. 单打抢七（3x），主要是保持较好的站位。
5. 一名运动员进行封网练习（2×3分钟）。
6. 练习第一发球计分（1×5/5分钟）。
7. 单打比赛（一盘）。

建立优势的90°变线
1. 定向小场地练习。
2. 5分钟热身。
3. 斜线——右区及左区（2/2×3分钟）。
4. 线路—内侧击落地球变线（1×5分钟）。
5. 斜线90°变线击球（3/3×3分钟），90°变线时要有较好的站位。
6. 线路—内侧90°变线，90°变线击球时站位要好。
7. 一名运动员封网练习截击（2×3分钟）。
8. 带发球的4拍球计分练习。
9. 抢七比赛。

两次发球的线路
1. 一人网前一人后场的热身练习（1/1 x3/3分钟）。

2. 20个第二发球和接发球。
3. 斜线—右区及左区（2/2×4分钟）。
4. 上旋球对切削球（2×2/2分钟）。
5. 线路——内侧击落地球变线（1×5分钟），一发和二发。
6. 线路—内侧击落地90°变线球（2×5分钟），一发和二发。
7. 利用发球及接发球制造压力的计分比赛（2×5分钟）。
8. 单打比赛（一盘）。

建立优势的内侧落地击球
1. 上旋球热身（8分钟）。
2. 手抛球练习（反手，3分钟），集中练习左手位的反手球。
3. 斜线—右区及左区（1×3分钟）。
4. 斜线内侧落地球变线（2/2×3分钟）。
5. 20个第二发球及接发球的4.拍球练习，每10 个发球至少有一次上网截击。接发球回斜线。
6. 开放式中场练习（2×2/2分钟）。
7. 定向击球—关闭式击落地球变线（1×5分钟），有一发和二发。
8. 定向击球—关闭式击落地球90°变线（1×5分钟），有一发和二发。开放式90°变线落地球失误记两分。
9. 击关闭式落地球并回位（2×3/3分钟）。

建立优势的准备
1. 上旋球热身（8分钟）。

2. 斜线——右区及左区（1/1×3分钟）。
3. 击斜线内侧落地变线球（1/1×3分钟）。
4. 一名球员封网截击（2×3分钟）。
5. 线路——内侧变线（1×5分钟），一发和二发两次发球。
6. 线路—内侧90°变线（1×5分钟），一发和二发两次发球。90°变线球失误记失两分。
7. 单打比赛（两盘）。

建立优势并强调发球落点
1. 定点小场地练习。
2. 手抛球（正、反手各1.5筐球）。
3. 20个第二发球及接发球。
4. 线路—右区及左区（3/3×4分钟）。
5. 线路——内侧变线（2×5分钟）。
6. 练习发外角和内角球（左右区各5分钟）。
7. 第一拍击球计分练习（1×5/5 分钟），落点是外角或内角。
8. 单打比赛（一盘），注意练习发球的落点（外角或内角）。

施加压力——内侧击落地球

目的：提高创造击内侧落地球机会的能力，使内侧落地球技术更加完美。

内侧击球是底线相持过程中第一个施加压力的机会，但许

多运动员这方面的意识不强。学会捕提机会并利用内侧击球给对手施加压力，是下面的练习所要达到的目标。

防守对方的内侧击球
1. 5分钟热身练习。
2. 4回合的20个第二发球和接发球时放小球。
3. 斜线—右区和左区（2/2×3分钟）。
4. 进攻与防守（3×2/2分钟）。
5. 外侧与中路击球（2×2/2分钟）。
6. 内侧击落地球并回位（2×3/3分钟）。
7. 单打练习（一盘）。

利用内侧击球给对手施压
1. 5分钟热身（正反手各1分钟）。
2. 手抛球练习（左右区各1分钟的内侧送球）。
3. 4回合的接发球施加压力（锥形物作为击球目标）。
4. 斜线—右区和左区（1/1×3分钟）。
5. 击斜线和内侧变线落地球（1/1×3分钟）。
6. 线路——内侧击球和90°变线落地球（2×5分钟）。90°变线失误记失两分。
7. 发球与接发球施压的计分练习（1×5分钟）。
8. 单打比赛（一盘）。

从中场1/3处施压
1. 5分钟热身。

2. 斜线——右区和左区（3/3×3分钟）。
3. 4回合的20个第二发球及接发球。
4. 手抛球练习（向正、反手各抛半筐球）。
5. 外侧/中场击球练习（2×3/3分钟）。
6. 第一发球计分练习（1×5/5分钟），落点为外角和内角。
7. 单打比赛（一盘），第一发球落点练习（外角或内角）。

随球上网回击内侧球
1. 上旋球热身（8分钟）。
2. 手抛球练习（向正、反手内侧各抛半筐球）。
3. 斜线—右区及左区（1/1×3分钟），发球上网。
4. 击斜线落地球变线（1/1×3分钟），击球后必须随球上网。
5. 击斜线和内侧落地球变线（1/1×3分钟），有时发球上网。
6. 内侧击球后回位。（2×3/3分钟）。
7. 线路—击内侧落地球变线（3×5分钟），击球后必须上网回击内侧球。
8. 4回合的接发球施压练习（锥形物为击球目标）。
9. 通过发球和接发球施加压力（2×5分钟）。
10. 单打抢七或抢11（3×5分钟）。

内侧落地球，发球及接发球施加压力
1. 上旋球热身（8分钟）。
2. 斜线—右区和左区（2/2×3分钟）。

3. 内侧击球后回位练习（2×3/3分钟）。
4. 线路—内侧击90°变线球（3×5分钟）。必须在随球上网时才能击90°变线球。
5. 4回合接发球给对手施压（锥形物为击球目标）。
6. 第一拍击球计分练习（2×3/3分钟）。
7. 单打比赛（一盘）。

击内侧落地球及站位
1. 定向小场地练习。
2. 5分钟热身。
3. 斜线—右区和左区（3×3分钟）。
4. 温布尔登式练习（3×3分钟）。
5. 线路——击内侧落地球变线（3×5分钟），击球后必须随球上网。
6. 内侧击球后回位练习（2×3/3分钟）。
7. 20个发球的4拍击球练习。
8. 第一发球计分练习（2×3/3分钟）。
9. 单打比赛（一盘）。

内侧及侧身内侧击落地球
1. 手抛球练习（抛正反手球，2×3分钟），连续两个外侧球和1个内侧球。
2. 4回合的20个第二发球及接发球练习。
3. 内侧击球后回位（2×3分钟）。
4. 斜线—右区及左区（2/2×3分钟）。
5. 击斜线和内侧落地球变线（1/1×3分钟）。

6. 线路—击内侧落地球变线（2×5分钟）。
7. 线路——击侧身内侧正手球（1×5分钟）。
8. 利用发球和接发球施加压力的计分练习（1×3/3分钟）。
9. 单打抢七。

内侧落地球——得分武器
1. 定向小场地练习。
2. 5分钟热身。
3. 手抛球练习——连抛三球，即侧身内侧正手、侧身内侧正手和内侧正手。
4. 斜线——右区和左区（2/2×3分钟）。
5. 斜线——侧身内侧正手（右区，2×2/2分钟）。
6. 斜线——侧身内侧正手（3×5分钟）。
7. 单打比赛（一盘），发球得分计得两分。

内侧正手施压
1. 5分钟热身。
2. 手抛球练习（向内侧正、反手，各抛1.5筐球）。
3. 斜线——左区和右区（2/2×3分钟）。
4. 一名球员封网截击（2×4分钟）。
5. 外侧与中场击球练习（2×2/2分钟）。
6. 内侧击球后回位练习（2×3/3分钟）。
7. 第一发球计分练习（2×3/3分钟）。
8. 单打抢七。

通过内侧落地球及凌空球给对手施压
1. 定向小场地练习。
2. 5分钟热身。
3. 斜线—右区和左区（1/1×3分钟），其中一局必须发球上网。
4. 斜线——侧身内侧正手击球（右区，2×2/2分钟）。
5. 线路—侧身内侧正手击球（2×5分钟）。
6. 一球员上网截击（2×4分钟）。
7. 内侧击球后回位（1×3/3分钟），在左区送半高球。
8. 内侧击球后回位（2×3/3分钟），在右区送半高球或一般落地球。
9. 高压球计分练习。
10. 单打抢七比赛。

施加压力——外侧击落地球（90°变线）
目的：提高判断及掌握变线球时机的能力，熟练掌握击90°变线球的技术。

通常让运动员站在底线内或底线上，击球时利用90°变线或打直线。运动员需要正确判断下一球是不是施加压力变线的好机会，要区分变与不变的基本原则。

直线进攻
1. 上旋球热身（8分钟）。

2. 手抛球练习（抛球使运动员击90°变线球，1/1 × 2/2分钟）。
3. 对拉斜线上的90°变线（2/2×3分钟），其中一局必须发球上网。
4. 线路——内侧90°变线球（2×5分钟）。
5. 进攻与防守（2×2/2分钟），单打场地。
6. 第一发球计分练习（3×5分钟）。
7. 单打比赛（一盘）。

直线施压
1. 5分钟热身。
2. 手抛球练习（送90°变线球，1/1×2/2分钟）。
3. 斜线对拉 90°变线球（2/2×3分钟），变线时要注意场上位置。
4. 击外侧浅球后上网然后复位（2×3/3分钟）。
5. 一名运动员上网截击（3×3分钟）。
6. 第一拍球的计分练习（1×3/3分钟）。
7. 单打比赛（一盘）。

90°变线
1. 定向小场地练习。
2. 5分钟热身。
3. 斜线——右区和左区（2/2×3分钟）。
4. 击外侧浅球后上网（2×3/3分钟）。
5. 斜线90°变线（2/2×3分钟），变线时注意场上位置。
6. 线路—内侧90°变线球（2×5分钟）。

7. 线路—猛烈地正手进攻击球（2×5分钟）。
8. 4 回合20个第二发球及接发球练习。
9. 单打比赛（一盘）。

施加压力—第一发球及接第二发球
目的：用第一发球和接第二发球控制场上的主动，建立对第一发球和接第二发球争取主动的基本意识。

利用发球与接发球争取场上主动是这个练习的主要目的。

网球中的每一分都是从发球和接发球开始的，结果也常取决于发球者和接发球者的第一拍球。积极进攻的意识在现代网球中是十分必要的。

发球和接发球练习
1. 上旋球热身（8分钟）。
2. 斜线——右区和左区（2/2×3分钟）。
3. 线路—击内侧落地球变线（2×5分钟）。
4. 20个第二发球和接发球，发球落点为外角。
5. 第一发球计分练习（2×6分钟），重点是发外角球。
6. 单打比赛（两盘）。

快节奏练习
1. 一前一后对打练习（2/2×3/3分钟）。
2. 20个4回合第二发球（锥形物为击球目标）。
3. 斜线—右区和左区（1/1×3分钟），一旦发球上网，

接发球者必须在左区用正手击球。
4. 一名运动员上网截击（2×3分钟）。
5. 进攻与防守（2×2/2分钟）。
6. 第一发球计分练习（3×5分钟）。
7. 单打比赛（一盘）。

发球上网练习
1. 上旋球热身（8分钟）。
2. 斜线——右区和左区（1/1×3分钟），发球上网一次。
3. 线路—击内侧90°变线球（2×5分钟），一发时必须上网。
4. 一名运动员上网截击（2×3分钟）。
5. 单打发球上网（2×4分钟），两次发球。接发球遵照回球线路原则。
6. 单打比赛（一盘）。

发球及接发球施压
1. 5分钟热身。
2. 手抛球练习（抛正手和反手球，每组1.5筐球）。
3. 两人同时发20个第二发球。
4. 4回合接发球施加压力（锥形物为击球目标）。

站位

目的：运动员要利用积极的场上站位体现战术意识并给对手制造压力。

站在底线上或以内击球是最有效的施压手段之一。此时，运动员往往能够感觉到恰当的击球时机，即是底线击球还是选择舒适的位置击球。如果运动员向前移，就会逼迫对手向后移，使对手击球较浅，失去击球角度，只有招架之力。所以要积极地选择好站位，主动站在场内击球。

场内击球练习
1. 小场地线路练习。
2. 手抛送球（送正手和反手随击球，每组1.5筐球）。
3. 接发球施加压力，击4拍球（锥形物为击球目标）。
4. 斜线—右区和左区（2/2×4分钟）。
5. 一名球员上网截击（3×3分钟）。
6. 温布尔登式练习（3×3分钟）。
7. 抢七（3×3分钟），全场温布尔登式抢七。
8. 单打比赛（一盘）。

温布尔登式定向击球练习

3. 斜线—右区和左区（2/2×3分钟），其中一局必须

发球上网。
4. 温布尔登式线路击球（2×5分钟），侧身击内侧正手90°变线球。
5. 单打发球上网（2×4分钟）。接发球遵照线路原则，有两次发球机会。
6. 用发球和接发球施加压力（1×5分钟），发向外角或内角。
7. 单打比赛（一盘）。

温布尔登式网球
1. 一前一后热身练习（1/1×3/3分钟）。
2. 斜线—右区和左区（1/1×3分钟）。

4. 一名球员上网截击（3×3分钟）。

双打发球和接发球

目的：集中练习第一发球和接发球。

从战术上讲，双打主要是第一发球和接发球，出色的第一发球可以给接发球方造成巨大的压力，为同伴在网前迅速得分创造条件。好的接发球能抑制发球方的一拦，从而为同伴创造机会抢网得分。双打中的发球要强调落点和旋转而不是速度，

一小时训练

目的：培养运动员一小时内自我训练的能力。

这个练习是运动员根据自我需要的自主练习。5个练习阶段包括基本技术、旋转球、施加压力、进攻与防守及双打与凌空球练习。
### 基本技术练习
1. 小场地线路练习。
2. 斜线—右区和左区（3/3×3分钟）。
3. 基本线路和内侧变线球（3×5分钟）。
4. 4回合20 个第二发球及接发球。
5. 第一拍击球计分练习。

6. 比赛。注意成功率——对击球方式和变线的正确选择。

旋转球
1. 小场地切削球线路练习。
2. 斜线—右区和左区（1/1×4分钟），发球后必须上网。
3. 切削球对切削球（2×3分钟），单打场地。
4. 抽球对上旋球（2×2/2分钟）。
5. 抽球对切削球（2×2/2分钟）。
6. 抢七，每分有两次发球机会。
a. 全部使用切削球。
b.变化—连续两拍不同的旋转球。
c.正常—无规定（仍要思考旋转球的变化）。
7. 比赛。思考变化—将球打到对手不擅长击球的区域。

施压
1. 上旋球热身练习（8分钟）。
2. 斜线—右区和左区（1/1×4分钟），有时发球上网。
3. 线路—击内侧落地球变线（2× 5分钟），每次循环必须发球上网一次。
4. 抢网截击（2×2/2分钟），半块双打场地。
5. 击内侧落地球并回位（2×3/3分钟）。
6. 迎前击外侧浅球并回位（2×3/3分钟）。
7．比赛。

进攻与防守
1. 手抛送球（正反手，每组送1.5 筐球）。
3. 斜线—右区和左区（1/1×4分钟），有时发球上网。
3. 进攻与防守（3×2/2分钟）。
4. 击外侧中场球（2×3/3分钟）。
5. 第一拍击球计分练习（2×3/3分钟）。
6. 比赛。
### 双打与凌空球练习
1. 截击热身练习（1/1×3/3分钟）。
2. 斜线——右区和左区（1/1×4分钟），有时发球上网。
3. 一名运动员近网截击（1×3分钟）。
4. 两名运动员近网对拦（2×3分钟）。
5. 双打斜线发球上网（1对1）：
a. 接发球者必须留在底线（1/1×4分钟）。
b. 接发球者进攻—回球后必须上网（1/1×4分钟）。
c.接发球者自由选择—上网或留在底线（1/1 ×4分钟）。
6. 比赛。主要练习接发球和一拦。
